Vestmark asked API Evangelist to remove this repository and any information
related to Vestmark from the API Evangelist network. That request was honored
on **2026-08-08**.

## What was here

A third-party profile of Vestmark, built by API Evangelist's secondary-market
harvest from Vestmark's public corporate website. It catalogued zero APIs — the
profile recorded that Vestmark serves no public developer host and that its
integration documentation sits behind an authenticated customer community.

## What was removed

Everything except this notice: the `apis.yml` profile, the security and
well-known artifacts, the conformance and llms.txt artifacts, the blog pull,
the scoring artifacts, and every page and index entry across
[apis.io](https://apis.io/) and [apievangelist.com](https://apievangelist.com/).
Vestmark is unlisted and unrated across the network.

Vestmark is recorded in the network's permanent delisting registry, which every
harvest, enrichment and scoring pipeline consults before adding a company. It
will not be re-listed.

## Why this repository still exists

It is kept as a removal notice only, so that links pointing here do not fail
silently and so the record of the request and its handling remains public.
There is no data in it.

## Removal requests

API Evangelist honors removal requests without requiring the requester to
establish standing. Email **info@apievangelist.com** or open an issue on
[api-search/inbox](https://github.com/api-search/inbox).
